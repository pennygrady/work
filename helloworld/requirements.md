# helloworld 项目需求文档

## 1. 项目概述

开发一个极简的 C 语言 "Hello World" 程序，用于验证 C 开发环境及项目构建流程。

## 2. 功能需求

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| FR-1 | 程序执行时在标准输出打印字符串 `helloworld` | 必须 |
| FR-2 | 程序正常退出，返回状态码 0 | 必须 |

## 3. 非功能需求

| 编号 | 需求描述 |
|------|----------|
| NFR-1 | 纯 C 实现，单个 `.c` 源文件，无外部依赖（仅标准库） |
| NFR-2 | 可使用 gcc 编译通过，无警告（`-Wall`） |
| NFR-3 | 跨平台可移植（Windows / Linux / macOS） |

## 4. 验收标准

1. `gcc -Wall -o helloworld helloworld.c` 编译成功，无错误无警告。
2. 运行生成的可执行文件，标准输出包含 `helloworld`。
3. 程序退出码为 0。

## 5. 约束与假设

- 使用标准 C（C99 或以上）。
- 仅使用 `stdio.h` 标准库。
- 无需命令行参数、无需用户交互。

## 6. 需求确认

> 项目极简，按任务指示跳过需求确认门，直接进入架构设计。
