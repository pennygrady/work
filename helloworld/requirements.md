# HelloWorld 项目需求文档

- 版本：v1.0
- 日期：2026-10-07
- 状态：已确认

## 1. 项目概述

开发一个极简的 C 语言 HelloWorld 项目：单个纯 C 源文件，编译执行后向标准输出打印 `helloworld`。本项目同时作为标准工程结构（源码 + Makefile + 文档）的模板示例。

## 2. 用户故事

- **US-1**：作为一名开发者，我希望执行编译出的程序后能在终端看到 `helloworld` 输出，以验证编译环境与项目结构可用。
- **US-2**：作为一名开发者，我希望使用一条命令（如 `make`）即可完成编译，以便快速构建和清理。
- **US-3**：作为一名代码审查者，我希望代码遵循统一的风格与目录规范，以便阅读和后续扩展。

## 3. 需求明确项

### 3.1 编译环境

| 项目 | 约定 |
| --- | --- |
| 编译器 | GCC（优先），兼容 Clang（`-Wall -Wextra` 下无警告） |
| 语言标准 | C11（`-std=c11`） |
| 目标平台 | 跨平台：Windows（MinGW/MSYS2）与 Linux/macOS 均可编译运行 |
| 构建产物 | 可执行文件 `helloworld`（Windows 下为 `helloworld.exe`） |

### 3.2 构建脚本

- 需要提供 **Makefile**，包含以下目标：
  - `all`（默认）：编译生成可执行文件
  - `run`：编译并运行
  - `clean`：删除构建产物
- 编译参数约定：`CC ?= gcc`，`CFLAGS = -std=c11 -Wall -Wextra -O2`

### 3.3 代码风格与目录规范

- 代码风格：
  - K&R / Linux 内核风格大括号；4 空格缩进，不使用 Tab
  - `int main(void)` 签名，显式 `return 0;`
  - 仅包含必要头文件（`<stdio.h>`），使用 `printf("helloworld\n");`
  - 文件头部包含简短注释（文件名、用途）
- 目录结构：

```
work/helloworld/
├── requirements.md   # 本文档
├── Makefile          # 构建脚本
└── src/
    └── main.c        # 唯一源文件
```

## 4. 功能清单

| 编号 | 功能 | 优先级 |
| --- | --- | --- |
| F-1 | 程序启动后向标准输出打印一行 `helloworld` 并以换行结尾 | P0 |
| F-2 | 提供 Makefile 支持 `make` / `make run` / `make clean` | P0 |
| F-3 | 程序正常退出，返回退出码 0 | P0 |

## 5. 验收标准

| 编号 | 验收标准 | 验证方式 |
| --- | --- | --- |
| AC-1 | 在项目根目录执行 `make` 可成功编译，无编译警告 | 手动执行 |
| AC-2 | 运行生成的可执行文件，标准输出**精确**为 `helloworld\n`（无其他内容） | 运行并比对输出 |
| AC-3 | 程序退出码为 0 | 检查退出码 |
| AC-4 | `make clean` 后构建产物被完全删除 | 手动执行并检查目录 |
| AC-5 | 使用 GCC 与 Clang 分别以 `-Wall -Wextra` 编译均无警告 | 手动执行 |

## 6. 非目标（Out of Scope）

- 不支持命令行参数、国际化、日志框架等扩展功能
- 不引入 CMake/自动化测试框架等额外工具链（保持极简）
